Almacenamiento y publicación

Funciona en GitHub Pages. Conecta Supabase para compartir registros entre dispositivos.

Modo local: los registros se conservan en este navegador. Los demás compañeros no podrán verlos desde otros dispositivos hasta conectar la nube.
Instrucciones de instalación y seguridad

1. Sube este archivo como index.html a tu repositorio GitHub Pages. 2. Crea un proyecto Supabase y ejecuta el SQL del archivo supabase_setup.sql en SQL Editor. 3. Copia la URL y clave pública del proyecto aquí. 4. Comparte el enlace con los compañeros.

Importante: La configuración SQL de demostración permite inscripciones públicas y consulta pública de perfiles. Para un uso real con datos personales, limita el acceso mediante autenticación, consentimiento informado, moderación y políticas de privacidad. Nunca coloques una service_role o clave secreta en HTML.

El PDF original está incrustado en esta página, por lo que su formato permanece intacto. Los datos se rellenan en los campos existentes; la fotografía solo se muestra en el directorio.
